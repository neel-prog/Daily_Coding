1. OS Detection using Nmap

sudo nmap -O <TARGET_IP>

2. OS + Service Detection

sudo nmap -A <TARGET_IP>

3. OS Detection with Version Scan

sudo nmap -O -sV <TARGET_IP>

4. Check SNMP Port

sudo nmap -sU -p 161 <TARGET_IP>

5. SNMP Enumeration using snmpwalk

snmpwalk -v2c -c public <TARGET_IP>

6. System Information

snmpwalk -v2c -c public <TARGET_IP> 1.3.6.1.2.1.1

7. System Description

snmpwalk -v2c -c public <TARGET_IP> 1.3.6.1.2.1.1.1

8. System Name

snmpwalk -v2c -c public <TARGET_IP> 1.3.6.1.2.1.1.5

9. Network Interfaces

snmpwalk -v2c -c public <TARGET_IP> 1.3.6.1.2.1.2

10. Interface Information

snmpwalk -v2c -c public <TARGET_IP> 1.3.6.1.2.1.2.2

11. SNMP Enumeration with Nmap

sudo nmap -sU -p 161 --script snmp-info <TARGET_IP>

12. SNMP Scripts

ls /usr/share/nmap/scripts/ | grep snmp

13. snmp-check

snmp-check <TARGET_IP>
